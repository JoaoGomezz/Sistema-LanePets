# PROMPT_RETOMADA.md

## Prompt para uma nova conversa após o limite

Vou continuar um projeto que estava sendo desenvolvido em outra conversa.

Os arquivos atuais do projeto estão anexados nesta conversa.

Primeiro leia:
- `REGRAS_PROJETO.md`
- `CONTINUACAO_PROJETO.md`

Depois analise os arquivos reais e compare com o estado registrado.

Não recomece o projeto.
Não refaça páginas já concluídas.
Não invente funcionalidades.
Não crie dados fictícios.
Não migre o modelo de dados nesta fase.

Preserve:
- `localStorage`;
- IDs usados pelo JavaScript;
- funções existentes;
- regras de negócio;
- navegação;
- backup/restore.

Use:
- `design-system.css`;
- `ui-kit.js`.

Identifique a primeira tarefa pendente e execute-a diretamente nos arquivos.

Quando terminar:
1. valide o JavaScript com `node --check` quando aplicável;
2. revise a navegação;
3. revise responsividade;
4. verifique se as funcionalidades continuam preservadas;
5. atualize `CONTINUACAO_PROJETO.md`;
6. informe exatamente o que foi feito.

Não fique apenas descrevendo código. Faça as alterações no projeto.
